# 🛡️ FIVE Network Security Suite

A professional, Python-based toolkit designed for network administrators, security researchers, and enthusiasts to perform authorized infrastructure stress testing and reconnaissance.

---

## 🚀 Overview

The **FIVE Suite** consists of two core modules designed to work in tandem:

1. **FIVE DOS**: A high-performance infrastructure stress-tester with support for multiple attack vectors and external API integration (VIP Layer).
2. **FIVE SCANNER**: A multithreaded reconnaissance tool used to identify open ports and analyze target service availability before performing stress tests.

---

## 🛠️ Features

### [1] FIVE DOS (Stress Module)
- **Multi-Vector Support**: UDP-Flood, TCP-Storm, and HTTPS-TLS (Layer 7).
- **API Integration**: Connect to high-capacity clusters for up to 50 Gbps throughput.
- **Custom Intensity**: Adjustable flood speed and thread management.
- **Modern UI**: Dark-themed GUI with real-time logging and status reporting.

### [2] FIVE SCANNER (Recon Module)
- **Fast Port Discovery**: Multithreaded scanning of common service ports.
- **Target Intelligence**: Automated IP resolution and connectivity checks.
- **Security Audit**: Identifies potential entry points for authorized testing.
